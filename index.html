Advanced: use a personal access token
Unauthenticated requests are limited to 60/hour, shared by everyone on your network. A token (no scopes needed for public repos) raises that to 5,000/hour. The token is kept in this browser tab only — it is never sent anywhere but api.github.com, and is not saved to disk or committed to this repo.

Repositories

Each repo's title is read from the first # Heading line of its README (falling back to the repo name if none is found). Authors are the repo's top GitHub contributors, most active first.

Data comes live from the GitHub REST API on every page load — nothing here is cached or pre-built.
